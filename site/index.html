Cómo llega esta página aquí

  1. Alguien hace git push a la rama main.
  2. El job pruebas corre pytest en una máquina limpia (CI).
  3. Si las pruebas pasan, el job publicar completa esta página con el commit y la fecha, y la despliega en GitHub Pages (CD).
  4. Si alguna prueba falla, no se publica nada y queda en línea la última versión buena.
